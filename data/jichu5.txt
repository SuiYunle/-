# 中医常识与禁忌（AI知识库用结构化文本）


## 【模块概览】

中医学强调“治未病”与“以平为期”，不仅重视对疾病的治疗，更重视日常生活中的调摄宜忌。所谓“忌”，即避免与疾病、体质、季节、药物等不相适应的行为或饮食，以免损伤正气、诱发或加重疾病。本部分从服药禁忌、饮食禁忌、特殊人群禁忌、生活起居禁忌、情志禁忌五个维度，系统梳理中医常识与禁忌知识。

本部分涵盖以下核心模块：

- **模块A：服药禁忌**（十八反、十九畏、服药期间饮食禁忌、服药时间与方法禁忌、药物-食物特殊禁忌）
- **模块B：饮食禁忌（忌口）** （发物分类、体质忌口、病证忌口、四季忌口、地域忌口）
- **模块C：特殊人群禁忌**（妇女、小儿、老年人）
- **模块D：生活起居禁忌**（沐浴禁忌、睡眠禁忌、房事禁忌、劳逸禁忌）
- **模块E：情志禁忌**（七情过极、情志调摄禁忌）


## 模块A：服药禁忌

### A.1 服药禁忌的基本概念

服药禁忌是中医用药安全的重要保障，主要包括配伍禁忌、证候用药禁忌、妊娠用药禁忌和服药期间的饮食禁忌四个方面。中药的用药禁忌主要包括配伍禁忌、证候用药禁忌、妊娠禁忌和服药时的饮食禁忌等。

### A.2 配伍禁忌——十八反与十九畏

配伍禁忌是指某些药物在合用时会产生剧烈的毒副作用或降低和破坏药效，因此应该避免配合应用，主要包括“十八反”和“十九畏”。

#### A.2.1 十八反

十八反是指两种药物配伍应用后会产生毒性反应或副作用。据古代文献记载，有歌诀如下：

> **十八反歌诀**：
> “本草明言十八反，半蒌贝蔹及攻乌，
> 藻戟遂芫俱战草，诸参辛芍叛藜芦。”

**十八反药物对照表**：

| 主药 | 相反药物（不可同用） |
|-----|-------------------|
| 乌头（包括川乌、草乌、附子） | 半夏、瓜蒌（天花粉）、贝母（浙贝、川贝）、白及、白蔹 |
| 甘草 | 甘遂、京大戟、红大戟、海藻、芫花 |
| 藜芦 | 人参、西洋参、党参、丹参、玄参、北沙参、南沙参、苦参、细辛、白芍、赤芍 |

#### A.2.2 十九畏

十九畏是指两药合用时，一种药物会受到另一种药物的抑制，使其功效降低或毒副作用增强。

> **十九畏歌诀**：
> “硫黄原是火中精，朴硝一见便相争。水银莫与砒霜见，狼毒最怕密陀僧。
> 巴豆性烈最为上，偏与牵牛不顺情。丁香莫与郁金见，牙硝难合京三棱。
> 川乌草乌不顺犀（角），人参最怕五灵脂。官桂善能调冷气，若逢石脂便相欺。”

**十九畏药物对照表**：

| 药物甲 | 药物乙（畏） |
|-------|------------|
| 硫磺 | 朴硝（芒硝） |
| 水银 | 砒霜 |
| 狼毒 | 密陀僧 |
| 巴豆 | 牵牛 |
| 丁香 | 郁金 |
| 牙硝（芒硝） | 三棱 |
| 川乌、草乌 | 犀角 |
| 人参 | 五灵脂 |
| 官桂（肉桂） | 赤石脂 |

**重要说明**：《中国药典》1963年版“凡例”中明确规定“注明畏、恶、反，系指一般情况下不宜同用”。古代医家认为反药同用“相反则彼我交仇，必不宜合”，现代临床研究也有不少报道反药同用引起中毒的例证。

### A.3 服药期间的饮食禁忌

服药期间应忌食生冷、油腻、腥膻、辛辣等刺激性食物，如生胡荽、鸡、生菜肥猪、犬肉、油腻肥羹、鱼鲙、腥臊等食物。

#### A.3.1 五类通用忌口食物

| 食物类别 | 常见食物 | 禁忌原因 |
|---------|---------|---------|
| 辛辣类 | 葱、蒜、韭菜、生姜、酒、辣椒等 | 性辛热，易生痰动火、散气耗血，抵消清热滋阴药物功效 |
| 生冷类 | 生鲜水果蔬菜、冰淇淋、冷饮等 | 性质寒凉，损伤脾胃阳气，影响胃肠功能和药效 |
| 油腻类 | 动物油脂、煎炸食物（炸鸡、汉堡、烧烤等） | 影响脾胃运化，阻碍药物吸收 |
| 鱼腥类 | 黄鱼、鲤鱼、带鱼、虾、螃蟹等 | 含异性蛋白，易引起过敏，属发物 |
| 酸涩类 | 杨梅、醋、浓茶等 | 含鞣质，与蛋白质、生物碱结合沉淀，影响吸收 |

酸涩类食物大多含鞣质，可与中药中的某些蛋白质、生物碱、重金属盐结合产生沉淀，这就会影响药物有效成分的吸收，同时对蛋白质等营养物质的吸收也有影响。服用中草药时，一般不宜与浓茶同服。

#### A.3.2 特定药物-食物特殊禁忌

根据古代文献记载，特定药物有特殊的饮食禁忌（应灵活掌握，科学对待，有的内容有待临床进一步证实）：

| 药物 | 禁忌食物 |
|-----|---------|
| 人参 | 萝卜（因萝卜破气，降低补药效力） |
| 薄荷 | 甲鱼（鳖肉） |
| 茯苓 | 醋 |
| 鳖甲 | 苋菜 |
| 天门冬 | 鲤鱼 |
| 地黄、何首乌 | 萝卜 |
| 白术 | 大蒜、桃、李 |
| 黄连、桔梗 | 猪肉 |
| 甘草 | 菘菜（白菜）、海藻 |
| 半夏、菖蒲 | 饴糖、羊肉 |
| 常山 | 生葱、生菜 |

### A.4 服药时间与方法禁忌

服药方法直接影响药效。《卫生易简方》记载：若疾病位于胸膈以上，应先吃饭再服药；若疾病位于心腹以下，应先服药再吃饭；若疾病位于四肢血脉，宜空腹服用，最好在早晨服用；若疾病位于骨髓，宜饱食后服用，最好在晚上服用。

### A.5 证候用药禁忌

中药治病的原理是以药物之偏性纠正人体之偏性。寒病热之，热病寒之是治疗原则。比如寒凉药物能清热，治疗热证，那么治疗时期要禁止吃冷饮。辛温药物治疗寒证可以祛寒但是又能伤阴，所以治疗时期不宜食用辛辣燥热食物。

### A.6 中药服用误区提示

服用中药期间需注意：忌自行增减药量或同时服用其他药物。若需服用其他药物，应先咨询医生，以防药物相互作用影响疗效。特殊人群（孕妇、哺乳期妇女、儿童及老年人）用药需更加谨慎，遵循医生建议。


## 模块B：饮食禁忌（忌口）

### B.1 忌口的基本概念

“忌口”是在中医“药食同源”的基础上发展而来，通过合理的饮食提高疗效、减少复发、增强体质。狭义忌口指患病时在饮食方面的禁忌；广义忌口还包括因年龄、体质、地区和季节的不同而忌服或少服某些食品，也包括为避免某些病情复发而忌服某些“发物”等。

### B.2 发物分类

发物是指能引起旧疾复发、新病增重的食物。此类食物均为动风生痰助火之品，由于疾病对食物选择程度的大小不同，其“发”亦有异。

| 发物类别 | 具体食物 | 禁忌人群/病证 |
|---------|---------|-------------|
| 动风发物 | 茄子、木耳、猪头肉、鸡蛋、公鸡肉、鹅肉 | 荨麻疹、皮肤瘙痒、哮喘、动风患者 |
| 海腥发物 | 虾、蟹、带鱼、黄鱼、鲤鱼、蚌肉等 | 过敏体质、脾胃病、皮肤病 |
| 辛辣发物 | 葱、姜、蒜、辣椒、花椒、酒 | 内热证、阴虚阳亢、血证、痈疖 |
| 生发发物 | 蘑菇、香蕈、笋、芥菜、南瓜、荞麦、豆芽 | 疔疖疮痈、皮肤病、肠胃病 |
| 肥甘发物 | 肥猪肉、狗肉、动物内脏、油炸食品 | 痰湿体质、肥胖、心脑血管疾病 |

通常情况下，“发物”泛指辛辣、燥热、生冷、肥甘厚味的食物，包括带鱼、鲤鱼、蛤蜊、螃蟹、虾、羊肉、香菜、芒果、荔枝、杨梅等。是否忌食，要因人、因病、因治法而异。

### B.3 按体质忌口

#### B.3.1 体质偏实者（湿热质、痰湿质、瘀血质）
“邪气盛则实”，不宜再补充过度的营养，尤其要减少脂肪的摄入，可以多吃含有丰富膳食纤维的食物，同时加强锻炼，避免发展成代谢性疾病。

#### B.3.2 体质偏虚者

| 体质类型 | 忌口原则 | 具体禁忌 |
|---------|---------|---------|
| 阳虚者 | 忌寒凉、生冷食物，不宜过食凉性瓜果菜肴 | 冷饮、生冷水果、凉性蔬菜 |
| 阴虚者 | 忌温燥伤阴食物 | 葱、姜、蒜、辣椒等辛辣刺激食物 |
| 气虚者 | 忌耗气、滋腻难化食物 | 肥腻、油煎、干硬等难以消化的食物 |

但虚证者不可补益过度，尤其不能多吃肥腻、油煎、干硬等难以消化的食物，而要在补中有疏，以清淡和富于营养为宜。

### B.4 按病证忌口

根据中医文献记载，古代医家把患病期间所忌食的食物高度概括为以下几大类：

| 类别 | 具体食物 | 主要禁忌人群 |
|-----|---------|------------|
| 生冷类 | 冷饮、冷食、大量生蔬菜和水果 | 脾胃虚寒腹泻患者 |
| 黏滑类 | 糯米、大麦、小麦等所制的米面食品 | 脾虚纳呆、外感初起患者 |
| 油腻类 | 荤油、肥肉、煎炸食品、乳制品 | 脾湿或痰湿患者 |
| 腥膻类 | 海鱼、无鳞鱼、虾蟹、海味、羊肉、狗肉 | 风热证、痰热证、斑疹疮疡患者 |
| 辛辣类 | 葱、姜、蒜、辣椒、花椒、韭菜、酒、烟 | 内热证患者 |

**按寒热虚实原则**：

- **寒证**：治疗原则为益气温中、散寒健脾。宜食温性热性饮食物，忌用寒凉、生冷食物。
- **热证**：治疗原则为清热、生津、养阴。宜食寒凉性质的食物，忌食温燥伤阴的食物。
- **虚证**：阳虚者宜温补，忌用寒凉；阴虚者宜清补，忌用温热。
- **实证**：饮食宜忌要根据辨证情况标本兼治，或者急则治其标，缓则治其本，抓住主要矛盾才能配合药治而获良效。

### B.5 按四季忌口

中医“天人合一”理论提示我们应根据人体对外界气候的反应，适时调整饮食。

| 季节 | 气候特点 | 忌口原则 | 具体禁忌 |
|-----|---------|---------|---------|
| 春季 | 多湿，阳气升发，肝胆气旺 | 减酸宜甘，培养脾气 | 不宜油腻辛辣，以免内生火热 |
| 夏季 | 热邪挟湿，脾胃受困 | 以甘淡、清爽为主 | 避免油腻，特别是不要贪食生冷瓜果 |
| 秋季 | 燥气当令，燥易伤肺 | 滋阴润肺 | 少食辛辣，不宜过食辛温大补之品 |
| 冬季 | 万物封藏，寒邪正盛 | 可进温补 | 勿食冷食 |

### B.6 按地域忌口

《黄帝内经素问·异法方宜论》指出，不同地域的人由于环境与饮食习惯不同，可能会诱发相关的疾病。如东方之人“食鱼而嗜咸”，多发痈疡；西方之人“华食而脂肥”，易发内风；北方之人多乳食，多“脏寒生满病”；南方之人“嗜酸而食腐”，地域多湿，易发挛痹。虽然当时的情况已与现在有所差异，但也提示我们可以在饮食上就当地所缺乏的物质以及多发的疾病做相应的补充和调整，减少疾病易发的因素。


## 模块C：特殊人群禁忌

### C.1 妇女禁忌

#### C.1.1 妊娠期
妊娠期，母体脏腑经络之气血注于冲任经脉，以养胎元。孕期应注意营养均衡，食物品种多样化，适食多餐。勿嗜过咸、过甜食物，忌烟酒、辛辣、油腻、刺激等食物，减少食物对胃肠道刺激。

**妊娠用药禁忌**是指妇女妊娠期治疗时应避免使用的药物。某些药物可能损害胎元，导致堕胎。根据药物对胎元损害程度的不同，一般可分为慎用与禁用两大类。

- **禁用药**：毒性较强或药性猛烈的药物，如巴豆、牵牛、大戟等。凡属禁用的药物，不能用。
- **慎用药**：包括去淤、行气破滞及辛热滑利之品，如桃仁、红花、牛膝、大黄等。属慎用的药物，以不用为好，但若有必要，可根据孕妇的具体病情酌情使用。

**妊娠禁用的中成药**包括：牛黄解毒片（丸）、木瓜丸、丁公藤风湿药酒（禁内服，可外擦患处，但忌擦腹部）、小金丸、小活络丸、开胸顺气丸、木香槟榔丸、化症回生片、玉真散、失笑散、七厘散、九气拈痛丸、九分散、大黄蟅虫丸、再造丸、当归龙荟丸、红灵散、苏合香丸、阿魏化痞膏、纯阳正气丸、冠心苏合丸、紫雪、活血止痛散、益母草膏、跌打丸、跌打活血散、痛经丸、暖脐膏、暑症丸、痧药、醒消丸、鳖甲煎丸等。

**妊娠慎用的中成药**包括：黄连上清丸、凉膈散、祛风舒筋丸、三妙丸、万氏牛黄清心丸、万应锭、女金丸、天麻丸、五虎散、牛黄上清丸、分清五淋丸、龙胆泻肝丸、伤湿止痛膏、安宫牛黄丸（散）、防风通圣丸、妇科分清丸、沉香化气丸、鸡血藤膏、栀子金花丸、通关散、清肺抑火丸、清胃黄连丸、舒肝丸、舒筋活络酒、附子理中丸、尪痹冲剂等。

#### C.1.2 哺乳期
哺乳期除补气养血之外，还应多补充矿物质、微量元素，保证母乳中的营养。哺乳期妇女要考虑药物是否通过乳汁影响婴儿，用药需谨慎。

#### C.1.3 月经期
妇女经期如果身体平时健康，只要饮食规律即可，但要慎食冷物，以免血管过度收缩引起痛经。平时身体虚弱者，应注意在经后服用一些补气养血的温性食品，如大枣、红糖、鸡蛋、龙眼等，对于寒凉食物与辛热食物皆应忌服。

### C.2 小儿禁忌

小儿时期“脾常不足”，所吃的食物应与其消化功能适应，注意摄入优质蛋白质以及维生素、矿物质。吃了不舒服或拉肚子的东西就记住不再吃。

- 小儿用药剂量需根据年龄、体重调整。
- 古代文献记载：小儿勿与莲实、芡实食，食之不长（过量食用影响消化吸收）。

### C.3 老年人禁忌

老人脏腑衰退、化源不足，应以温热熟软的食物为主，节制脂肪和糖类，多吃清淡素食，忌黏硬生冷的食物。

老年人因器官功能及肌肉骨骼韧带组织强度可能存在减退，日常起卧、改变体位时需谨慎，谨防诱发心脑血管疾病、肌肉韧带组织扭伤、跌扑损伤等情况。老年人多有基础疾病，用药需综合考虑。


## 模块D：生活起居禁忌

### D.1 起居调摄总纲

中医调摄的五大核心原则：“避风寒、慎起居、畅情志、节饮食、勿作劳”。言语虽简，却是对中医养生调摄理念的高度概括。

### D.2 沐浴禁忌

古代医籍对沐浴禁忌有详细记载：

#### D.2.1 沐浴环境与水温
沐浴必须在密室内进行，水温不得太热，也不得太冷，过冷过热均易引发各种疾病。冬浴不宜汗出过多。沐浴后不得吹风受凉。新洗头后不要迎着风，不要湿着头发睡觉，易致头风眩晕、发秃面黑、齿痛耳聋、头生白屑。

#### D.2.2 沐浴时间
饥饿时忌洗澡，吃饱后忌洗头。晚上洗头后不吃东西就睡觉，会令人心虚、多汗多梦。沐浴后身体未干不可睡觉。频繁沐浴者，气血凝滞而气机散乱，身体虽润泽但正气自损，易生痈疽之疾。

#### D.2.3 其他沐浴禁忌
- 食饱不可洗头，不宜用冷水淋头
- 病后新汗解，勿用冷水洗浴，损心包不能复
- 过夜的炊汤洗体成癣，洗面无光，洗脚疼痛
- 热泔洗头、冷水灌之，作头风

### D.3 睡眠禁忌

#### D.3.1 睡眠姿势与环境
- 卧宜侧身屈膝，不损心气；觉宜舒展，精神不散；舒卧招邪魅。
- 枕内安麝辟邪，安决明子、菊花明目。
- 濯足而卧，四肢无冷疾。
- 睡不可张口，泄气损气。
- 寝不得言语，五臟如悬磬然，不悬不可发声。
- 灯烛而卧，神魂不安，尤忌行房。口吹灯则损气。
- 夜勿燃灯睡，魂魄不守。

#### D.3.2 睡前禁忌
- 沐浴未干不可睡。
- 饱食后不宜立即入睡
- 夜间不宜说鬼神事（恐致心神不宁）。

#### D.3.3 睡眠中的异常处理
若人睡觉时被魇（梦魇）不语，是魂魄外游为邪所执，宜暗唤，或以梁上尘吹鼻中即醒。忌以火照，则神魂不入。不宜近唤及急唤，亦恐失神魂。

### D.4 房事禁忌

- 夫妻不用同室沐浴
- 如患目赤病，切忌房事，不然令人生内障
- “以妄为常，醉以入房，以欲节其精者”是损伤肾精的大忌

### D.5 劳逸禁忌——“五劳所伤”

《黄帝内经》及养生古籍中总结了过度劳逸的危害：

| 劳逸类型 | 所伤部位 | 说明 |
|---------|---------|------|
| 久视 | 伤血 | 目受血而能视，久视过度耗伤肝血 |
| 久卧 | 伤气 | 气贵流通，久卧不动则气机壅滞 |
| 久坐 | 伤肉 | 脾主肌肉，久坐不动损伤脾气 |
| 久立 | 伤骨 | 肾主骨，久立伤肾损骨 |
| 久行 | 伤筋 | 肝主筋，久行过度耗伤肝血 |

### D.6 避风寒禁忌

风寒邪气趁人体虚而入，引发外感疾病症状（如常见的感冒、咳嗽、鼻塞、发热、身体疼痛等），如治疗失当或病情迁延，则容易发生变证。

**具体禁忌**：

- 沐浴勿当风，腠理百窍皆开，切忌邪风易入。
- 不可登高履崄，奔走车马，气乱神惊，魂魄飞散。
- 大风大雨、大寒大热，不可出入妄为。
- 当处于室外气温剧烈变化时、房内有风时、出入空调房间、沐浴后、饮酒后、房事后需注意避风、保暖。腹部及脐周尤需注意保暖。
- 涉水淋雨后应及时擦干，有条件宜热水沐浴；出汗后要及时更换湿衣。

### D.7 其他起居禁忌

- **坐卧禁忌**：坐卧勿当风湿地；夜勿燃灯睡，魂魄不守；昼勿睡，损元气。
- **出行禁忌**：阴雾中不可远行。
- **视听禁忌**：凡日光射，勿凝视，损人目；勿望远极目观，损眼力。
- **日常保健**：凡人自觉十日以上康健，即须灸三数穴，以泄风气。每用必须调气补泻，按摩导引为佳。勿以康健便为常然，须常安不忘危，预防诸病也。


## 模块E：情志禁忌

### E.1 七情过极之禁忌

七情（喜、怒、忧、思、悲、恐、惊）在正常情况下是人体对外界环境刺激的生理反应，不会致病。但若突然、强烈或长期持久的情志刺激超过了人体正常的生理活动范围，导致人体气机紊乱、脏腑阴阳气血失调，就会引发疾病。

情志失调可能影响气血运行，干扰药效发挥。服药期间应保持心情舒畅，避免过度紧张、焦虑、愤怒等不良情绪。

| 七情 | 禁忌表现 | 对机体的影响 |
|-----|---------|------------|
| 喜 | 暴喜过度 | 喜则气缓，心气涣散，神不守舍 |
| 怒 | 暴怒不止 | 怒则气上，肝气上逆，气血冲头 |
| 忧 | 过度忧愁 | 忧伤脾肺，气机郁滞，意志消沉 |
| 思 | 思虑过度 | 思则气结，脾气郁结，运化失常 |
| 悲 | 悲伤过极 | 悲则气消，肺气耗伤，呼吸气短 |
| 恐 | 恐惧过度 | 恐则气下，肾气不固，精气下泄 |
| 惊 | 突受惊恐 | 惊则气乱，心神失守，气机紊乱 |

### E.2 情志调摄禁忌

《黄帝内经》言“恬淡虚无，真气从之，精神内守，病安从来”。从防病角度而言，保持精神思维活动的清静内守，精、气、形可得到休养生息，对机体具有积极的休养调节作用。从疾病的康复角度来讲，调畅情志、清静内守，使得机体气机调达，有利于疾病的康复。

**情志调摄禁忌要点**：

- 不可暴怒，生气疾恶疮。
- 夜行勿歌唱大叫。
- 夜间不宜说鬼神事（恐伤肾精）。
- 情志疾病随着现今生活质量的提高与节奏的加快而越来越常见。调畅情志不仅可防病延年，还可疗疾愈病。

### AI学习使用要点

1. **十八反/十九畏歌诀**可转化为“药物-相反药物”映射表，用于用药安全提示和配伍冲突预警。

2. **发物分类**中的“食物类别→禁忌人群/病证”映射关系，可支持AI根据用户输入的体质或病证信息自动推荐应忌口的食物。

3. **体质忌口**的“阳虚忌寒凉、阴虚忌温燥”等对称性规则，可作为个性化饮食指导的推理基础。

4. **四季忌口**可结合当前季节自动生成时令忌口建议。

5. **特殊人群禁忌**应作为问诊流程中的条件分支触发——若用户为孕妇、小儿或老年人，自动激活相应禁忌提示。

6. **生活起居禁忌**中的“五劳所伤”（久视伤血、久卧伤气等）可作为健康提醒功能的知识依据，用于日常养生建议生成。

7. **五类通用忌口食物**的“类别→常见食物→禁忌原因”三元组结构，可用于“症状→推荐忌口”的推理链条。例如：热证（症状）→忌辛辣（类别）→葱姜蒜辣椒（具体食物）→性辛热易助火（原因）。

8. **禁忌的灵活性原则**：忌口需因人、因病、因治法而异，AI系统应避免绝对化的禁忌表述，提示用户“具体忌口请遵医嘱”。

### 术语规范化说明

本知识库中的名词术语依据国家中医药管理局名词术语规范及中医养生古籍文献进行规范。十八反、十九畏等内容参照《中国药典》及相关权威教材。可用于AI系统的统一概念索引和知识检索。部分古代养生文献中的禁忌内容（如沐浴后不吹风、饱不洗头等）虽源自古籍，但在现代生活中仍具有实用参考价值，建议AI系统在提示时结合现代生活场景进行合理转化。
